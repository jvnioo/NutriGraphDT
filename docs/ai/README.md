# AI-Assisted Development Guide

NutriGraphDT allows AI-assisted development under the same engineering, scientific, documentation, and review standards applied to human-written contributions.

Start with the repository root [`AGENTS.md`](../../AGENTS.md).

## Policies

- [`ai-development-policy.md`](ai-development-policy.md) — human responsibility, scope control, verification, privacy, and tool-neutral AI usage.
- [`coding-standards.md`](coding-standards.md) — Python, design, dependency, reproducibility, and code-quality rules.
- [`source-policy.md`](source-policy.md) — hierarchy and verification of technical/scientific sources.
- [`scientific-integrity.md`](scientific-integrity.md) — evidence, assumptions, data, experiments, constraints, explainability, and interpretation.
- [`../documentation-policy.md`](../documentation-policy.md) — technical/user documentation, experiment records, scientific evidence, academic-report material, and potential paper material.

## Repository skills

Codex-compatible project skills live under `.agents/skills/`:

- `implement-issue`
- `review-code`
- `research-reference`
- `testing`
- `document-project`

They are workflows, not independent authorities. `AGENTS.md`, the current Issue, and repository policies remain canonical.

## Contributor responsibility

AI-generated output must be inspected by the contributor before it enters a Pull Request. A model response is never sufficient evidence that code works, a test passed, a citation is valid, or a biological conclusion is supported.
