# Configuration

Versioned experiment, model, data, and simulation configuration will live here as the corresponding project phases are implemented.

Do not add placeholder configuration merely to populate the directory. Configuration should represent an executable or documented project decision.

## Contents

- `sources.json` — registered data sources (A34-1).
- `splits/` — versioned train/val/test splits (A40-1).
- `cohorts/` — supervised cohort per dataset: required targets, SSU read threshold and excluded
  animals with their reason (#138); see
  [`docs/data-sources/holofood-source.md`](../docs/data-sources/holofood-source.md#cohorte-supervisada-138).
- `baselines/` — hyperparameter grids of the non-graph baselines, JSON (A40-4, A40-5).
- `training/` — `TrainingConfig` JSON files: `default.json` (A44-4) and
  `test_constrained_cycle.json`, the small constrained configuration (λ = 0.5 with the D-06
  bound) of the synthetic full-cycle integration test (A66-P4, #184).
- `constraints/` — versioned λ sweep configurations of the constrained arm, one per dataset
  (`lambda_sweep_d1.json`, `lambda_sweep_synthetic.json`; A68-P1, #178); see
  [`docs/models/constraints-lambda-sweep.md`](../docs/models/constraints-lambda-sweep.md).
- `models/` — one YAML per GNN variant read by `build_model` (A41-8); see
  [`docs/models/gnn-model-config.md`](../docs/models/gnn-model-config.md).
- `functions/` — `scfa_produces_d1.tsv`, the `function → produces → metabolite` relations
  approved for D1 (KEGG orthologs of the terminal SCFA-releasing step, #257), and
  `has_capacity_d1.tsv`, which of those orthologs each `1:1` genus carries in the MGnify chicken-gut
  v1.0.1 catalogue (#175, generated by `scripts/build_capacity_table.py`); see
  [`docs/research/decision_produces_D1.md`](../docs/research/decision_produces_D1.md).
- `taxonomy/` — SILVA 132 → GTDB r207 genus equivalence table (S-04, contract v2 §6):
  `s04_silva132_gtdb_r207.tsv` covers the 498 genera of D1 (#236) and replaces the minimal
  `s04_silva_gtdb_minimal.tsv`; see
  [`docs/research/decision_has_capacity_D1.md`](../docs/research/decision_has_capacity_D1.md).
